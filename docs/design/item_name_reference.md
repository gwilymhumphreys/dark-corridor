# Item Name Reference — Diablo 2 Base Items

A list to pull from when naming weapons and armour. These are the base item names from Diablo 2
and its expansion, with the unique and set names left out. They are here because the register is
right for this game: plain medieval equipment names, with enough odd and archaic ones to avoid a
pool that reads as generic.

Use them as a starting point rather than a source to copy from wholesale. A name taken directly is
recognisable to anyone who played that game.

The spelling is Diablo's own American "Armor" inside the item names. Our own text uses British
"armour".

Within each group the names run roughly from the weakest item to the strongest, which is how the
source orders them. That ordering is not a tier system here, just the order they came in.
